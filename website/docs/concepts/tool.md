# Tool

## 内置 Tool

| Tool | 说明 |
|------|------|
| read_file | 读取文件 |
| write_file | 写入文件 |
| shell | 执行命令 |
| http_get/post | HTTP 请求 |
| save_memory | 保存记忆 |
| recall_memory | 检索记忆 |
| notify | 通知推送 |

## Plugin 三档

| 方式 | 门槛 |
|------|------|
| SKILL.md + MCP | 零代码 |
| 自写 MCP server | 轻代码 |
| @Tool 注解 | 重代码 |
