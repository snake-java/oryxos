# Quick Start

## Requirements

- JDK 21+
- Maven 3.9+

## Build

```bash
mvn clean package
```

## Start Server

```bash
java -jar oryxos-boot/target/oryxos-boot-*.jar serve
```

## Interactive Chat

```bash
java -jar oryxos-boot/target/oryxos-boot-*.jar chat
```

## One-click Start

```bash
./bin/start.sh
```
